## Reproducibility

To maintain academic rigor and verify that logs were generated authentically rather than crafted manually, an automated evaluation script is provided. This script replays the thesis conversational prompts against Ollama and the FastAPI backend, logging full multi-turn conversations in JSON format.

### Automated Execution (Recommended)

```bash
# 1. Start operations backend (required for LLM tool invocation)
uvicorn app.infrastructure.main:app --port 8000 &

# 2. Verify Ollama is running with the target model
ollama serve &
ollama pull qwen2.5:7b

# 3. Execute the reproducibility pipeline
PYTHONPATH=. python3 scripts/generate_demos.py
```

### Manual Interactive Execution (Frontend)

Scenarios can also be reproduced interactively through the conversational UI:

```bash
LLM_PROVIDER=ollama OLLAMA_MODEL=qwen2.5:7b streamlit run app/agent_layer/chat_app.py
```
